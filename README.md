# Issues Faced by Software Practitioners When Using User Stories: An Empirical Study Based on Stack Exchange Discussions

## Replication Package

This repository contains the replication package for the paper titled **"Issues Faced by Software Practitioners When Using User Stories: An Empirical Study Based on Stack Exchange Discussions"**.

The package is composed of the study dataset and its license file.

## Repository Contents

The package contains the following artifacts:

- **dataset - Issues Faced by Software Practitioners When Using User Stories An Empirical Study Based on Stack Exchange Discussions.xlsx**: The master spreadsheet containing the dataset, coding results, and aggregated analyses used in the study.
- **LICENSE.txt**: The license file describing the terms under which this repository is shared.

## Spreadsheet Description (`dataset - Issues Faced by Software Practitioners When Using User Stories An Empirical Study Based on Stack Exchange Discussions.xlsx`)

The main spreadsheet is organized into the following sheets to facilitate inspection and replication:

- **Critérios**: Inclusion and exclusion criteria adopted to determine whether a Stack Exchange discussion was suitable for analysis.
- **Lista Geral**: Master list of retrieved discussions, including identifiers, source forum/community, title, criterion, year, and additional metadata.
- **Piloto-Consenso**: Pilot screening and consensus sheet, containing the independent decisions made by the researchers during the selection process.
- **Análise para RQs**: Consolidated dataset used for the research questions, including the selected discussions and the final coding for problems, problem types, agile methodology, ceremony, role, effects, and possible solutions.
- **Análise RQ1 Issues**: Aggregated analysis of the issues identified in the dataset, relating problem types and final issue codes.
- **Análise RQ1 Metodolgia**: Aggregated analysis of agile methodologies associated with the identified issues.
- **Análise RQ1 Cerimônias**: Aggregated analysis of agile ceremonies associated with the identified issues.
- **Análise RQ1 Papel**: Aggregated analysis of practitioner roles associated with the identified issues.
- **Análise RQ1 Efeito**: Aggregated analysis of the effects related to the identified issues.
- **Análise RQ1 Efeito X tipo Probl**: Cross-analysis relating effect categories and problem types.
- **Cópia de Análise RQ1 Efeito X t**: Auxiliary copy of the effect-versus-problem-type analysis sheet.
- **Cópia de Cópia de Análise RQ1 E**: Additional auxiliary summary sheet relating problem types and effect categories.
- **Análise RQ2 Soluções**: Analysis of possible solutions discussed in the posts, including final solution codes, meta-solutions, and categories.
- **Tabela dinâmica 2**: Summary table counting occurrences of meta-solutions.
- **Cópia de Tabela dinâmica 2**: Auxiliary summary table grouping solutions by category.
- **Cópia de Cópia de Tabela dinâmi**: Additional auxiliary table relating problem types and solution categories.

## Usage

Researchers may use this spreadsheet to inspect the dataset, review the coding process, and understand how the findings reported in the paper were organized and summarized.

## Anonymous Review

This repository may be shared in anonymized form for peer review. Therefore, author-identifying information is intentionally omitted from this replication package.
